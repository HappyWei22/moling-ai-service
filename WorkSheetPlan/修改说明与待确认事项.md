# WorksheetPlan v0.3 修改说明与待确认事项

日期：2026-09-14。用途：同学之间复核修订稿，尚不是已共同签字确认的最终协议。
对照原 v0.2 文件，修订内容已接入当前模拟模块。原文件在 history/original-v0.2/，不要用于新版调用。

## 逐条修改

1. **先只做临摹**：task_type 从描红、临摹、默写、纠错四选一改为只允许“临摹”。先展示范字，让用户照着写；其他形式以后再讨论。
2. **不做评测和过关判定**：新版没有 evaluation。v0.2 第二次交付已经去掉该字段，本轮继续保持，不把它算作本轮新删除的字段。
3. **指导语改为可选**：instruction 可以不写，也可以为 null；有需要时给练习提示，不表示系统已经评分。
4. **一项写一个字或词**：不要把“重点、例题、总结”当一项。拆成三个条目；当前只接收基本区和扩展 A 区汉字，标点、空格、其他字符拒绝。并非覆盖所有生僻汉字，也不能自动判断词语边界。
5. **说清重复单位**：“课堂” repeat=3 是整组写三遍，即 6 个填写字格。范字展示占的空间不计入填写格数。
6. **练习量改按字格计算**：取消“5/15/30 分钟分别 1/2/3 个任务”的数量规则。暂定改为 12/36/72 个填写字格，当前代码要求精确相等。这是本次为联调新增的工程假设，不是原作者提供的数据，不是经过实练验证的教学结论，需要重点确认。
7. **输出增加书体 style**：渲染端直接读取，不再从标题猜；当前模块原样保留输入书体。允许的书体名不代表字体文件和授权已经就绪。
8. **增加 schema_version 和 plan_id**：前者为业务格式版本 0.3，后者当前由模块每次生成一个 UUID。后端需要确认编号归属；目前重复调用会得到不同编号，不保证幂等。plan_name 保留作显示名称。
9. **书体、时长不能随意让步**：取消“职业/场景 > 书体 > 时长”的优先顺序。依据职业/场景选择内容时，不能擅自改变用户书体和时长，也不能忽略排除条件。
10. **明确非标准时长处理**：继续只接受 5/15/30；20 分钟等拒绝，不自动取近似档位。用户的原始时长可以保留在 UserRequirement 中，但不能直接进入当前规划。
11. **模拟能力边界说清楚**：样例全部改为 is_mock=true；当前运行固定选“课堂”“学习”，尚未实现个性化选词。exclusions 非空时暂时拒绝，因为没有可靠过滤能力；这是模拟器限制，不是永久业务规则。不得把推测背景写回用户需求。
12. **补充错误校验**：空列表、空文字、负数/字符串次数、不支持的练习形式、额外字段、总字格数不匹配均拒绝。单项合法不代表整份计划合理。
13. **补充渲染说明**：按 items 顺序显示范字和填写空格；纸张、字号、行列布局由渲染端处理。这里只是约定，尚未实现字帖渲染。
14. **完善 Schema 文档和维护方式**：规范版本为 JSON Schema 2020-12，补充标题、说明及字段中文解释。$defs/$ref 用于复用单项结构，pattern 限制字符。由 schemas.py 自动导出，避免两套定义各改各的；总格数运算仍需要 Python 校验，不能仅依赖 JSON Schema。
15. **补充正常/异常样例及测试**：三档正常样例、异常样例说明、5 个测试方法及子案例，另保留需求端 10 组样例验证。Python 业务错误映射 HTTP 422，非法输出属于程序错误，不混成用户输入问题。

## 请优先确认

- 第一版是否统一只做临摹？指导语可选是否同意？
- 是否同意每项一个字/词、整组重复、范字不计填写格？
- 12/36/72 格只是临时值：是否接受用于联调？谁负责实练校准？是否改成范围而非精确配额？
- 是否接受模拟器暂时拒绝非空排除要求、20 分钟等非标准时长？
- plan_id 由 AI 模块生成还是由业务后端生成？
- 渲染负责人能否按 style 和条目输出临摹字帖？字体授权和字符覆盖由谁确认？

## 如何看包

先看本文件，再看训练量规则.md、plans.json、worksheet_plan.schema.json、异常样例.json。
根目录代码用于复现当前实现，README 有运行说明。原作者历史文件只作对照。
本包不含虚拟环境、密钥或编辑器设置。

验证命令（先按 README 创建环境、安装 requirements.txt）：

```bash
python check_examples.py
python -m unittest -v test_worksheet_plan
python export_schemas.py --check
```

本机此前结果为需求 10/10 和输出 5 个测试方法通过。本轮版本尚未重新在 Windows 或真实浏览器中验收；当前计划不是已验证的教学方案。
