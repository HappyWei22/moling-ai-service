# WorksheetPlan v0.3 修订稿

本次按组内决定仅保留临摹，不含 AI 评测、评分、过关判定。原交付逐字保存在 history/original-v0.2，修订稿用于当前代码联调，尚待队友复核。

## 输入与约束

沿用 UserRequirement v0.3：状态 complete、无错误、书体和时长明确，职业/场景/目标至少一个非空白。不得将推测的背景写回用户需求。
用户书体、时长和排除要求不可因职业/场景偏好而被覆盖。当前仅支持 5/15/30 分钟，其他时长明确拒绝，不自动映射。模拟阶段尚无可靠排除过滤，非空 exclusions 暂时拒绝，不静默忽略。

## 条目与字格

每项 text 是一个字或词，第一版允许基本汉字和扩展 A 区汉字，不接受标点或空格；代码只能检查字符形式，词语边界由内容提供者保证。
repeat 表示整个 text 重复次数。例如课堂 × 3 为 6 个填写字格。总填写字格数 = sum(len(text) × repeat)。不包含展示范字。
取消按任务数确定训练量的规则。暂定联调配额为 5 分钟 12 格、15 分钟 36 格、30 分钟 72 格，使用精确配额以方便验证。这是工程假设，不是教学结论或实际耗时保证；后续实练校准时需同步模型、样例、测试和版本。

## 输出及渲染

schema_version 固定 0.3；plan_id 由当前模块生成 UUID，后端存储时可关联此编号，同一请求重复调用会生成新编号，不含幂等保证。plan_name 为显示名称；style 必须等于输入；duration_minutes 必须等于输入。
task_type 仅允许临摹；instruction 可省略或为 null。每项展示范字，并提供 len(text) × repeat 个空白练习格，按 items 顺序展示；每行格数、纸张、字号由渲染端决定。实际字体文件和字体授权/覆盖仍待渲染负责人确认，Schema 允许书体不代表字体已就绪。
当前生成器使用固定词语，is_mock 必须为 true，不声称完成职业/场景/目标相关选词，也不负责绘制字帖。

## 验收与异常

正常计划必须非空、重复次数为正整数、无额外字段、字格配额正确。20 分钟、空内容、标点分隔的内容、空条目列表、描红/默写/纠错类型、负数次数应拒绝。
业务输入不支持时抛出 RequirementNotReadyError，调试 HTTP 接口映射 422。非法输出是程序/规划错误，不应伪装成用户输入错误。examples 中异常记录是测试说明，不能作为 WorksheetPlan 成功响应。
JSON Schema 从 Pydantic 导出；跨字段字格校验由 Python model_validator 执行，纯 JSON Schema 校验不足以保证配额正确。
