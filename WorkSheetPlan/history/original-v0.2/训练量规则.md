# WorksheetPlan 训练量规则说明 (v0.2)

## 1. 必填与选填字段
- **必填字段**：书体（style）、时长（duration_minutes）。
- **三选一字段**：职业（occupation）、场景（scene）、目标（goal）至少提供一个。
- **缺失处理**：如果缺少职业/场景/目标中的某几项，系统应基于已有的一个字段进行合理推断生成计划，不得编造复杂背景。

## 2. 计算方法
严格根据用户输入的 `duration_minutes` 字段，将练习计划分为 5、15、30 分钟三档。

## 3. 优先级
生成计划时，优先满足：用户职业/场景 > 用户要求的书体 > 规定时长。

## 4. 时长与任务分配约定
- **5分钟**：仅安排 1 个任务（纯描红或简单临摹），避免用户产生疲劳。
- **15分钟**：安排 2 个任务（描红 + 临摹），保证基础练习量。
- **30分钟**：安排 3 个任务（讲解 + 练习 + 默写/纠错闭环），适合深度学习。
- **异常时长**：如用户提出 20 分钟等非标准时长，暂不自动映射到最近档位，进入异常计划样例。

## 5. 渲染约定
前端拿到此 JSON 后，直接按 `items` 数组顺序渲染，展示指导语。
