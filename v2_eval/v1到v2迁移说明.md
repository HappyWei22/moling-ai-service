## 6. 复现方式

```bash
python v2_eval/scripts/build_samples.py     # 生成 samples_v2.jsonl 并用上游 finalize_v2 回灌校验
python v2_eval/scripts/validate_v2.py       # 数量/覆盖/隔离/近重复校验
```

`build_samples.py` 会用 `parsing.parse_requirement_v2._finalize_v2` 对每条样本回灌，
任何一条标准答案与真实实现不一致都会中止构建并打印差异 —— 即**标注口径与代码行为强制同源**。
